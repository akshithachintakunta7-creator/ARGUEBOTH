ArgueBoth

A student project built with plain HTML, CSS and JavaScript, powered by the Groq API. No chat history is stored. Every response is generated for the current topic only.

Responsible use

AI responses can contain mistakes. Verifiable claims should be checked against primary sources. A compromise is not always the right answer — use these perspectives as a starting point, not a verdict.
