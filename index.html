ArgueBoth

A student project built with plain HTML, CSS and JavaScript, powered by the Groq API. No chat history is stored.

Responsible use

AI responses can contain mistakes. Verifiable claims should be checked against primary sources.

How ArgueBoth Works

ArgueBoth uses the Groq API (running the Llama-3.3-70b model) to generate balanced arguments in real-time.

Prompt Engineering: The secure backend forces the AI to return strict JSON, explicitly forbidding made-up statistics and ensuring a neutral tone.

Steelman Mode: When toggled, the AI generates a secondary set of arguments designed to present the opposing view in its strongest, most charitable light.

Privacy: No data is stored. Your topic is sent to the Worker, processed, and immediately discarded. The API key is safely hidden on the server.
